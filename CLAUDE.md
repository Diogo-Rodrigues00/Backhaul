# Backhaul
Plataforma de conexão de fretes por urgência (projeto de faculdade, Uniube).

## Stack
- Banco: PostgreSQL 18 + PostGIS (schema em database/schema.sql)
- Backend: Node.js + TypeScript (monólito modular)
- App: React Native (depois)

## Regras de trabalho
- O dono do projeto está aprendendo e vai defender o código ao vivo. Explique o porquê antes do como e deixe partes para ele escrever.
- Commits em português, no padrão feat:, fix:, docs:.
- Valores de ENUM sempre em minúsculo, sem acento.
- Nunca commitar senhas ou arquivos .env.
- Mudou o schema? Atualize database/schema.sql e docs/.

## Equipe
Vários membros commitam no mesmo repositório: rodar git pull antes de começar.
